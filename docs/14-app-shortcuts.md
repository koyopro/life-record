# 14. ホーム画面アイコンからの追加（App Shortcuts）

ホーム画面のアイコンを長押しして、そのまま書き始められるようにする。

```text
アイコンを長押し → 「タスクを追加」 → 入力欄が開いた /add → 書く → 追加
```

思いついたことを書き留めるまでの間を詰めるための導線。アプリを開いて一覧が
読み込まれるのを待ち、`t` か「＋」を押して入力欄を開く、という手順を省く。

## 14.1 出し方

Web App Manifest の `shortcuts` で出す（nuxt.config.ts の `pwa.manifest`）。

```json
{
  "shortcuts": [
    {
      "name": "タスクを追加",
      "short_name": "追加",
      "description": "入力欄を開いた状態で起動する",
      "url": "/add",
      "icons": [{ "src": "/icon-192.png", "sizes": "192x192", "type": "image/png" }]
    }
  ]
}
```

manifest だけで済み、Service Worker には何も足さない（共有の受付と同じ。
[13-share-target.md](13-share-target.md) 13.1）。

**項目は1つだけにする。** 増やすほど長押しの先から目当てを選ぶ手間が増え、
「速く書き始める」という目的が薄れる。「今日」を見るのはアイコンを普通に
押せば済む（manifest の `start_url` が `/today`）。

出るのは**ホーム画面に追加（インストール）した場合だけ**で、manifest が
読めていることも要る。インストールできる状態の作り方（`<VitePwaManifest />` と
`useCredentials`）は 13.1 と共通なので、そちらを参照。

## 14.2 追加の画面（app/pages/add.vue）

置くのは3つだけ。

- 入力欄（一覧と同じ `ItemComposer`。**開いた時点でフォーカスする**）
- 追加できたものの一覧（タイトル。押すと Item の画面へ）
- 「今日を見る」「タスクを見る」

一覧は載せない。一覧を出すと、その読み込みを待つあいだ画面が動き、
書いている途中で入力欄の位置がずれる。ここは書くためだけの画面にする。

### フォーカスすること

`ItemComposer` は既定では自動でフォーカスしない。一覧のある画面では、
フォーカスされていると一覧のキーボード操作（`j` / `k` など）が入力欄に
吸われ、スマートフォンでは勝手にキーボードが出るため
（[08-todo-management.md](08-todo-management.md) 8.4）。

この画面には一覧が無く、キーボードが出るのはむしろ望むところなので、
`autofocus` を付けて例外にする。狭い画面でも「＋」を押させずそのまま出す
（`inline`）。

### 続けて追加できる

追加すると入力欄は空になり、フォーカスはそのまま残る。何が入ったかは
「追加しました」の一覧で確かめられるので、続けて書くのに画面を移らなくてよい。

## 14.3 追加の経路

一覧の入力欄・共有の受付（`/share`）とまったく同じ経路を通る。
追加のためのデータモデルも API も足さない。

```text
app/pages/add.vue
  → buildItemDraft（app/utils/item-draft.ts）
  → useItemStore().create（IndexedDB へ書き、送信は列に積む）
```

- 初期状態は「未着手」（`status = backlog`）・期限は今日（buildItemDraft の既定）
- SmartAdd の記法（`^期限` `!重要度` `#タグ` `*繰り返し`）がそのまま効く
- オフラインでも追加でき、送信は繋がったときに行われる（[12-offline.md](12-offline.md)）

オフラインで開けるのも他の画面と同じ。`/add` への移動は Service Worker が
殻（`/offline-shell`）で受け、ブラウザ側でこの画面を描く（12.2）。

## 14.4 対応環境

- **Android Chrome** … 対応。主要な対象。
- **デスクトップの Chrome / Edge** … インストールすればタスクバー等の
  アイコンから同じ項目が出る。
- **iOS / iPadOS Safari** … manifest の `shortcuts` に未対応（長押ししても
  出ない）。`/add` を直接開くか、ショートカットアプリから開けば同じ画面になる。

なお、`autofocus` でキーボードまで開くかはブラウザによる。iOS Safari は
利用者の操作なしにキーボードを出さないため、入力欄を一度押す手間が残る。
ここを埋めるための作り込みはしない。

## 14.5 実機での確認

1. Android Chrome で本番の URL を開き、「ホーム画面に追加」でインストールする
2. ホーム画面のアイコンを長押しし、**タスクを追加** が出ることを確認する
3. 選ぶと `/add` が開き、入力欄にカーソルが入っている
4. 何か書いて「追加」を押すと、下に「追加しました」が出る
5. 「タスクを見る」でその Item があり、「未着手」・期限が今日であることを確認する

インストールせずに確認したいときは、`/add` を直接開けば画面と追加までを試せる。
